WHAT IT DOES

01

THE GRAPH IS THE PRODUCT

Findings are not a dead list. Click any entity to scan it and follow the trail. Recon is iterative, so the interface is too.

02

KEYLESS BY DEFAULT

Every core source is free and needs no API key, so it works the moment you install it. Optional keys only ever add sources, never unlock the basics.

03

LOCAL-FIRST AI

The investigation brief is written by your own Ollama model. No per-token bill, and nothing about the case leaves the machine.

02

WHAT IT DOESN'T DO

AUTHORIZED USE ONLY

It is for authorized work only: security research, CTFs, contracted recon, and assets you own. It is not for surveilling people.

It reads public, rate-limited sources. It does not breach anything, and it will not find what was never published.

It is a starting point, not a verdict. Every finding carries confidence and provenance precisely because open sources are often wrong.
