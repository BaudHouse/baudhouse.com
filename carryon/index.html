01

WHY IT IS DIFFERENT

DPAPI · APP-BOUND ENCRYPTION

Most "just copy your profile folder" advice quietly fails. Chrome and Edge encrypt passwords and cookies to the original Windows account — DPAPI, and since Chrome 127 in 2024, App-Bound Encryption. Copy those files to a new PC and they are unreadable.

CarryOn knows this and does the right thing per item. Bookmarks, history and autofill copy automatically everywhere. Firefox passwords, cookies and extensions move with the profile. Chrome and Edge passwords and cookies are sealed to the old machine, so it reduces those to one guided export and opens the import page for you on the new PC.

Everything it can move by copy, it moves. Everything it cannot, it detects, explains why, and walks you through — instead of pretending it copied.

02

WHAT IT DOES

01

IT KNOWS WHAT ACTUALLY MOVES

Per-item handling rather than a blind folder copy: what can be carried is carried, what is sealed to the old machine is flagged and guided, and the difference is stated plainly up front.

02

A VERIFIABLE BUNDLE

Everything lands in one bundle with checksums, so you can confirm it is intact before trusting it. Restore previews with a dry run first, and anything it overwrites is backed up.

03

NO STICK REQUIRED

Put the bundle on a USB stick, or send it straight to the new PC across your own network. Either way it never passes through anyone else’s cloud.

03

WHAT IT DOESN'T DO

THE HONEST PART

It cannot move Chrome or Edge saved passwords and cookies by copy. Windows seals them to the original machine, and no tool can honestly claim otherwise — so those become one guided export instead of a silent failure.

It is not a disk-imaging tool and not a backup product. It carries the state you would miss, not the whole machine.

It reads credential stores in order to migrate them, which is exactly the capability you should be sceptical of in software you did not build yourself. That is the argument for publishing the source.
